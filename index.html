01 // WHO IS HOLY?

SECURITY IS
A MINDSET.

Curiosity, discipline and continuous learning. Holy studies how systems break — reconnaissance, enumeration, privilege escalation, web flaws, Active Directory paths — then learns how to harden them: architecture, logging, least privilege, documentation. Practical experimentation over theory, always in authorized environments, always written down.

PROFILE // KHALIFA · WORKING AS HOLY

My name is Khalifa, and I do security work under the name HOLY. I'm a cybersecurity specialist in the making — drawn to the uncomfortable questions: how does this break, who can get in, and how do we stop them?

My path runs from the ground up: networking foundations with CCNA, security fundamentals with Security+, then practical penetration testing through eJPT and PNPT — reinforced by IT/Security internships at Hassan Allam, Microsoft, Kaspersky and Huawei, plus a home lab where I break and harden my own systems. Now I'm pushing toward red-team operations (CRTO) and advanced web exploitation (OSWE).

How I work: curiosity first, discipline always — authorized targets only, every test documented, every finding paired with a fix. I don't collect tools; I build judgment. Think like an attacker. Build like a defender.
